# 变更记录

## V1.3.0 — 2026-10-10

**入库逻辑**

- 入库门槛由单一的“复用 + 同一性漂移”改为三道门：R 复用、E 证据比对、D 难生成。通过任一门入 A 并记录是哪一道；D 门必须属于类型表并写得出具体失败表现，防止“重要即难”。
- 新增 `references/gates-and-taxonomy.md`：三道门的问法、难生成六类（文字与版式、复杂空间／机关、非常规姿态、多步特效／变形、群像与精确数量、非常规形态）、不应判 D 的情形。
- A 级资产必填 `gates`、`gate_reasons`、`deliverable_spec`（预制形态、必须包含项、轻量／完整）；含 D 门加 `generation_risk`。预制形态只写做什么，不写外观设计。入库理由由 `gate_reasons` 承担。
- 剧情功能字段（`narrative_function`、`dramatic_function`、`usage`）不再使用：清单只写与制作和资产画面有关的内容，HTML 不显示，校验提示删除。
- 道具 `asset_type` 必填，新增“版式包”“形态素材”。新增条件可见锚点、`weight_note`、`related_assets`。

**运行模式与防错**

- 三种运行模式：`full`、`delta`（带旧清单，输出变化区与新旧集号对照）、`preview`（只收稳定项，首页标“预研／非正式”）。新增 `references/delta-and-preview.md`。
- 新增 `meta.scene_index`（核对来源定位）与 `meta.naming_registry`（规范名／别名／带上下文的禁用写法，发现称谓漂移）。
- 新增场次定位约定：无标头转场用字母后缀，一个标头含多个地点时拆分。
- SOP 与 SKILL 增加“常见边界情形”：制作标注里的视觉描述、范围内无出镜的对象、范围切分带来的伏笔型证据、规则视觉的合并粒度。
- 新增 `scripts/validate_inventory.py`：渲染前校验结构、引用、重复 id、门与预制形态、模式要求、命名漂移、声音建议；旧版清单宽松检查，只给汇总提示。新增 `tests/run_tests.py`。

**声音建议**

- 声音建议改为默认提供：人物音色（主角／配角／群声）、固定 BGM 建议（`recurrence`、`scene_ids`）、场景与固定 BGM 对照、按集调用点。不需要时写 `meta.audio_skipped`。

**HTML**

- 重做：首页给出制作总表（一行一个资产），资产详情为可折叠卡片，只含必须包含项、可见锚点、状态卡、最可能出的错、制作约束、待确认。首页显示非预制项数量与入库门分布。V1.1／V1.2 的 JSON 仍可渲染。

**其他**

- 修正 SOP 中 A／B／C 表格分隔行缺列的问题；修复 Python 3.9 对超长模板行的编码误报；新增 `assets/example_inventory.json` 示例。
- 新增 SOP V1.3，V1.1、V1.2 留档。本 Skill 独立使用，不依赖其他 Skill 或项目文件。

## V1.2.0 — 2026-09-24

- 改为“跨镜头／跨集复用 + 可见同一性风险”的主资产门槛；一次关键动作或特写不再自动入库。
- 新增预制主资产／场景级参考／镜头内生成三级去向，普通虚弱、单次吐血、淤青和一次性道具默认不预制。
- 角色状态不再按办公室、手术、审讯等场景标签自动拆分；固定机关并入场景，死亡残响等归规则视觉。
- HTML 增加筛选依据与非预制项复盘，保留既有声音设计模块。
- 新增制作前整理 SOP V1.2；V1.1 保留留档。

## V1.1.0 — 2026-09-14

- 新增：角色“可制作状态卡”，按服装／鞋履或手持、发妆／遮挡、伤妆／污损、特效／可见限制和切换原因拆分。
- 新增：人物音色卡、可复用 BGM 库、按集／场景声音调用表与声音待确认项；HTML 同页预览。
- 明确：剧情功能标签不得替代视觉资产状态；剧本未写的服装和造型必须标为待角色设计确认。
- 新增：制作前整理 SOP V1.1，统一项目交付与版本验收。

- 明确：不续写、不出图、不生成提示词、不替代现有资产和视频制作 Skill。
