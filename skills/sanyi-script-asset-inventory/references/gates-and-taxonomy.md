# 入库三门与难生成类型表

本文件回答两个问题：一个候选项该不该预制；如果该，通过的是哪一道门。判断前先读 SOP 第 2 节的顺序，这里补充每道门的问法和例子。

## 为什么是三道门

预制资产有两种完全不同的价值，混在一起会让清单失真：

- **保持一致**（R、E）：同一个东西反复出现，生成多次会长得不一样。
- **保证出得来**（D）：只出现一次，但自己就很难生成对，没有参考图就会出错。

分开记录，制作端才知道某项该花大力气做完整资产包，还是只需要一张参考页。

## R 复用门

问法：

1. 它在几个镜头、几集出现？（单集多镜头也算，只要需要同一外观。）
2. 重生成时，哪个部分会让观众看出"不是同一个"？写出来：脸、服装、空间平面、文字、证物状态。

通过标准：多镜头或多集出现，且能写出具体漂移点。

例子：长期出场的角色基型；跨多集回访的主场景；反复出现的同一件道具。

## E 证据门

问法：

1. 后续剧情是否让观众或角色**比对**同一物？
2. 比对的是什么：纹样、伤痕、文字、位置、页序、持有人、数量？

通过标准：写得出"在哪两处比对什么"。镜头再少也入库，作为证据版式。

例子：先出现一次、后来被指认的物件；前后两次出现要对得上的文书；案卷照片里的同一张脸。

不通过：只是"同类物件"。同类针筒、刀具、杯子不能默认合并，除非正文明确是同一件。

## D 难生成门

问法：

1. 它属于下面六类中的哪一类？
2. **最可能出什么错**？（必须写具体，如"文字出乱码""机关方位前后颠倒""人数每次不一样"。）
3. 这个错会不会被观众一眼看出，或让后续镜头无法对齐？
4. 一张参考页或一组关键帧能不能解决？能就用 `weight: light`。

两条都要满足：属于某一类，并写得出具体失败表现。

| 类型 | 代号 | 典型难点 | 可考虑的预制形态 |
|---|---|---|---|
| 文字与版式 | T | 文书、屏幕界面、短信、表格、标签、横幅：易出乱码，字数、排版、页序漂移 | `layout_pages` |
| 复杂空间／机关 | S | 多房间连续动线、暗门／电梯／机关方位、固定陈设的数量与位置 | `space_plan` |
| 非常规姿态／拟人动作 | P | 非人主体做人的手势、特殊移动方式、需要精确肢体接触 | `pose_pack` |
| 多步特效／变形 | F | 多阶段变化、物体出入身体、被牵引拉回、变身 | `fx_keyframes` |
| 群像与精确数量 | M | 多主体同框、固定人数／物数、成排陈列 | `space_plan` 或 `photo_ref` |
| 非常规形态 | X | 半透明、灵魂、特殊伤态、与本体需要对齐的特殊呈现 | `form_sheet` |

## 不应判 D 的情况

- 普通表情、普通受伤、一次性吐血、普通食物、普通手持物。
- "这个镜头很重要"或"导演很在意"。重要不等于难。
- 正文没有写清楚怎么呈现，无法判断难在哪：先标待确认，不假设。
- 同一类型但项目里已有一套统一母版（如统一的转场特效）：并入该母版，不重复建。

## 与 R、E 叠加

一项可以同时通过多道门，`gates` 写成 `["R","D"]` 等。叠加时：

- `weight` 取最高：只要有 R 或 E，按 `full` 做；仅 D 则按 `light`。
- 每道通过的门都要写一句 `gate_reasons`，下游据此判断优先级。

## 例子（抽象示范，不对应任何具体项目）

| 候选 | 判断 | 理由 |
|---|---|---|
| 反复出现的主角基型 | R，full | 多集、脸与服装不能漂 |
| 第 3 集出现的手写便签，第 5 集有人指出"字不一样" | E，full | 有明确比对点；兼 T，文字易错 |
| 只出现一次的体检单，上面有关键数值被镜头特写 | D 的 T 类，light | 文字密度高，乱码会被看出；只需一页版式 |
| 单集出现、但机关共四个位置缠绕的密室 | S，light 或并入场景包 | 方位前后不一致会穿帮 |
| 非人角色做合十磕头的动作，贯穿多集 | P + R，full | 非常规姿态且长期出现 |
| 一次性吐血 | C | 普通状态，不难 |
| 短暂淤青 | C | 普通状态，不难 |
